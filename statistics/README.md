# Statistics Seminar

This directory contains materials and sample datasets used in a statistics seminar conducted in the author's laboratory.

## Contents

- [statistics_seminar.pdf](./statistics_seminar.pdf) — Seminar slides
- [data](./data/) — Sample datasets for statistical exercises

## Topics

- Introduction to R and RStudio
- Descriptive statistics and hypothesis testing
- t-tests
- Effect sizes and statistical power analysis
- Wilcoxon tests
- Analysis of variance (ANOVA)

## Notes

The sample datasets were created by the author for educational purposes.

Some analyses use **ANOVA-kun**, a statistical analysis tool developed by Ryuta Iseki.
